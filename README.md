# Desk Control Hub

## Overview

A device that can control smart home gadgets and play Spotify music, all from one place.

The Desk Control Hub uses the LVGL library to create a clean, easy-to-use interface. It connects to Govee Home and Spotify, allowing it to control smart home devices and manage music playback.

I chose a CrowPanel because it was the best deal I could find for getting both a display and an ESP32 in one package. I do plan to replace the CrowPanel's original casing with my own custom-designed case.

## Features

- **Smart Home Control:** Connects to Govee Home to control compatible smart home devices.
- **Spotify Integration:** Connects to Spotify to control music playback.
- **LVGL Interface:** Uses LVGL to create a clean and easy-to-navigate interface.
- **Bluetooth Audio:** Can connect directly to Bluetooth speakers or earbuds to play music without needing another device to handle the audio connection.
- **Custom Enclosure:** Plans to replace the original CrowPanel casing with a custom-designed enclosure.

## Hardware

The project uses a CrowPanel, which combines an ESP32 and display into one convenient package. This made it a good choice for keeping the project compact and affordable.

## Challenges and What I Learned

I learned a lot about working with both the Spotify and Govee APIs while developing this project. Both integrations proved to be pretty complex, but hopefully I got everything working in the end.

Of course, we'll never really know until I actually build it!
